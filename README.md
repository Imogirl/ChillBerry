## About ChillBerry

**ChillBerry** is a cute, colorful and relaxing mood-based web application built with the **MERN Stack** and **Tailwind CSS**.

Instead of feeling like a traditional management system, ChillBerry is designed as a small digital comfort space where users can check their mood, enjoy playful interactions, complete tiny positive activities and relax.

The project focuses heavily on **beautiful UI, smooth interactions, pastel colors and an enjoyable user experience**.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ChillBerry.git
cd ChillBerry
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file inside the `backend` folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```
